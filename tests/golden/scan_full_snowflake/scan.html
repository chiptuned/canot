Safeguards

  • Every SQL statement sent goes through a read-only guard: only SELECT, SHOW, DESCRIBE and ALTER SESSION SET statements go out. No write, no API activation, no parameter change.
  • Query users and roles pseudonymized with HMAC, using a salt drawn for this scan and never written; tag values hashed; locations reduced to the bucket.
  • Raw SQL text is never written: only normalized forms, with literals masked, leave collection.

Rules

  • Movement: recreated: DDL less than 7 days old with no later write; live: write less than 30 days old; frozen: older last write; not determined: writes not read.
  • Storage with no read: actual window of the view read, compared with 365 days; the blind spots of each view are listed in the finding.
  • Copy time: assumed throughput of 20 to 80 MB/s.
  • List prices are dated and sourced; they do not replace your contract price.
